    PATCH 请求原理与 C# 实现

    PATCH 请求

    PATCH 用于对资源进行部分更新，只发送需要修改的字段。

    特点

    • 非幂等（取决于实现）：某些 PATCH 操作可能不是幂等的
    • 节省带宽：只传输变更的字段
    • 灵活：支持 JSON Patch (RFC 6902) 或 JSON Merge Patch (RFC 7396)

    与 PUT 的区别

    PUT PATCH
    数据量 完整资源 只发送差异
    幂等 是 不一定
    遗漏字段 重置为默认值 保持不变
    效率 低（传输多） 高（传输少）

    使用场景

    • 只修改 email：PATCH /api/users/42 body: {"email": "new@b.com"}
    • 更新状态：PATCH /api/orders/500 body: {"status": "shipped"}
    • 修改配置项：PATCH /api/config body: {"theme": "dark"}

    C# 实现

    PATCH 请求基础

    `csharp using System.Net.Http; using System.Text; using System.Text.Json;

    var client = new HttpClient(); client.BaseAddress = new Uri("https://api.example.com");

    // 只更新 email 字段 var patchData = new { email = "newemail@example.com" }; var json = JsonSerializer.Serialize(patchData); var content = new StringContent(json, Encoding.UTF8, "application/json");

    var request = new HttpRequestMessage(HttpMethod.Patch, "/api/users/42") { Content = content };

    var response = await client.SendAsync(request); response.EnsureSuccessStatusCode(); `

    使用 HttpClient.PatchAsJsonAsync

    csharp // 需要 Microsoft.AspNet.WebApi.Client 包 var response = await client.PatchAsJsonAsync("/api/users/42", new { email = "new@example.com", age = 31 }); response.EnsureSuccessStatusCode();

    JSON Patch (RFC 6902)

    JSON Patch 是一种标准的 PATCH 格式，使用操作数组：

    `csharp var patch = new[] { new { op = "replace", path = "/email", value = "new@b.com" }, new { op = "add", path = "/tags/-", value = "vip" }, new { op = "remove", path = "/oldField" }, };

    var json = JsonSerializer.Serialize(patch); var content = new StringContent(json, Encoding.UTF8, "application/json-patch+json");

    var request = new HttpRequestMessage(HttpMethod.Patch, "/api/users/42") { Content = content }; var response = await client.SendAsync(request); `

    实际项目封装

    `csharp public class ApiClient { private readonly HttpClient _http;

    public ApiClient(HttpClient http) => _http = http;

public async Task<T?> PatchAsync<T>(string url, object patchData)
{
    var json = JsonSerializer.Serialize(patchData);
    var content = new StringContent(json, Encoding.UTF8, "application/json");
    var request = new HttpRequestMessage(HttpMethod.Patch, url) { Content = content };

    var response = await _http.SendAsync(request);
    response.EnsureSuccessStatusCode();

    var responseJson = await response.Content.ReadAsStringAsync();
    return JsonSerializer.Deserialize<T>(responseJson, new JsonSerializerOptions
    {
        PropertyNameCaseInsensitive = true
    });
}

    }

    // 使用 var api = new ApiClient(httpClient); var user = await api.PatchAsync("/api/users/42", new { age = 31 }); `
