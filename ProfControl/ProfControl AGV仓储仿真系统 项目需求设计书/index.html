    ProfControl AGV仓储仿真系统 项目需求设计书

    ProfControl AGV仓储仿真系统 项目需求设计书

    目标：基于 ProfControl V8 平台，设计一套完整的 AGV 仓储自动化仿真系统，覆盖 AGV 调度核心需求。 版本：v1.0 | 状态：待实现

    一、项目概述

    1.1 系统目标

    构建一个 4层立体仓库 的 AGV 调度仿真系统，模拟真实的 WMS（仓库管理系统）+ AGV 控制系统协同工作场景。

    1.2 环境参数

    参数 值
    楼层数 4层
    AGV 总数 50 台
    上线 AGV 数 30 台（可配置）
    升降梯 多部（每部同时载 1 台 AGV）
    库位填充率 50%（初始）
    仿真步长 1 秒（定时器轮询）

    1.3 物理模型

                          ┌─────────────────────────┐
                      │       WMS 系统层         │
                      │  (任务生成、库存管理)      │
                      └──────────┬──────────────┘
                                 │ 下发出入库任务
                      ┌──────────▼──────────────┐
                      │    AGV 调度系统层        │
                      │  (任务分配、路径规划、     │
                      │   状态机控制、跨层调度)    │
                      └──────────┬──────────────┘
                                 │ 控制指令
                      ┌──────────▼──────────────┐
                      │    AGV 执行层            │
                      │  (导航、取货、卸货、       │
                      │   充电、避让)            │
                      └─────────────────────────┘

    二、AGV 基础功能需求

    2.1 AGV 生命周期管理

    [离线] → [上线] → [空闲待命] → [执行任务] → [空闲待命] → ... → [下线]
                    ↓                    ↑
              [低电量→去充电] → [充电完成]
    功能 说明
    上线 AGV 从离线状态激活，随机分配到空闲库位，初始化电量为 50~100%
    下线 AGV 移出地图，电量归零，任务终止
    保持在线 上线 AGV 持续参与调度，除非手动下线或电量耗尽
    数量控制 支持动态配置上线 AGV 数量，超出部分自动下线

    2.2 AGV 状态定义

    状态 含义 可分配任务？
    空闲 无任务、无货、在线、不充电 ✅
    已分配 已被分配给某任务但尚未出发 ❌
    前往取货点 导航中 ❌
    到达取货点 到达起点，等待取货 ❌
    取货中 正在执行取货动作 ❌
    前往送货点 导航中 ❌
    到达送货点 到达终点，等待卸货 ❌
    送货中 正在执行卸货动作 ❌
    去充电 低电量自动前往充电站 ❌
    正在充电 在充电站充电 电量≥60%时可中断接任务
    离线 不在系统中 ❌

    2.3 AGV 属性面板

    属性名 类型 控件 说明
    状态 string TextBox 当前任务状态
    上线 bool TextBox 是否在线
    类型 string TextBox 当前任务类型（"入库"/"出库"）
    车体状况 string TextBox 充电状态描述
    当前电量 double TextBox 仿真电量值 0~100

    2.4 站台属性面板

    属性名 类型 控件 可配置
    上线 bool CheckBox ✅ 工程预配置
    当前楼层 int TextBox ✅ 工程预配置

    三、任务系统需求

    3.1 任务类型

    类型 路径 说明
    入库 生产口 → 库位 从生产口取货，送入指定库位
    出库 库位 → 出库口 从库位取货，送到出库口

    3.2 TaskInfo 实体设计

    字段 类型 说明
    ID string GUID 唯一标识
    TaskType enum 入库 / 出库
    OccurTime DateTime 任务创建时间
    WorkAgv IAgv 执行 AGV 引用
    FromSta IStation 取货起点站台
    ToSta IStation 送货终点站台
    Floor int 任务所在楼层
    Status string 状态机状态

    3.3 任务创建规则（WMS 模拟）

    入库任务触发条件

    • 生产口 有货物 + 无AGV在场 + 无未完成入库任务绑定
    • 目标库位：同楼层巷道中 从前往后 找第一个空库位
    • 防死锁：后续站点有入库任务则跳过当前位置

    出库任务触发条件

    • 出库口 空闲 + 计数器>=18秒 触发一次
    • 目标库位：同楼层巷道中 从后往前 找第一个有货库位
    • 防冲突：同一巷道已有出库任务则跳过

    并发控制

    • 系统同时存在的任务总数 ≤ 50
    • 未完成任务数 ≤ 50
    • 同一生产口/库位不能有多个未完成任务

    3.4 任务状态机（8状态）

                        ┌──────────────────────────────────────┐
                    │          任务状态机流转               │
                    │                                      │
      ① 初始("")──→② 找到Agv──→③ 前往取货点──→④ 到达取货点
                    │                                      │
                    │                                      │
      ⑧ 完成←──⑦ 送货中←──⑥ 到达送货点←──⑤ 前往送货点
                    └──────────────────────────────────────┘
    步骤 状态 入库动作 出库动作
    ① "" 找可用 AGV，分配任务 同左
    ② "找到Agv" GoTo(生产口) GoTo(库位)
    ③ "前往取货点" 检测到达，未到则重发导航 同左
    ④ "到达取货点" 执行"取货"动作集，货物站台→AGV 同左
    ⑤ "前往送货点" GoTo(库位) GoTo(出库口)
    ⑥ "到达送货点" 检测到达 同左
    ⑦ "送货中" 执行"复位"动作集，货物AGV→库位 执行"取货"动作集卸货
    ⑧ "完成" 清理标记、统计、释放AGV 同左

    四、AGV 调度策略需求

    4.1 AGV 选择优先级

    同楼层正常空闲AGV(电量>20%且不充电)
  → 同楼层充电中AGV(电量≥60%可中断)
    → 跨楼层调度(升降梯有余量且无重复调度标记)

    4.2 跨层调度

    • 当本楼层无可用空闲 AGV 时，从其他楼层调车支援
    • 调车路径：其他楼层 → 电梯口 → 乘电梯 → 目标楼层
    • 使用 HashSet<string> 防止同一楼层重复派车
    • 目标楼层已有空闲 AGV 到达时自动解除跨层标记
    • 升降梯容量上限 = 1（同时只能载一台 AGV）

    4.3 最短路径选车

    • 同层多台可用 AGV 时，选择距离取货点 最近 的一台
    • 使用 站点距离Agv集合中最近的一个() 扩展方法

    4.4 防推挤策略

    场景 策略
    上料点（生产口） ForbiddenPushWhenAgvOnWithoutCargo = true
    下料点（出库口） ForbiddenPushWhenAgvOnWithCargo = true
    任务执行中（取货/卸货） CanBePush = false 临时关闭
    导航途中 CanBePush = true 允许推挤

    五、电量与充电管理系统需求

    5.1 电量仿真

    参数 值 说明
    初始电量 50~100% 随机初始化
    消耗速率 0.0108/秒 每5秒减少一次，约9小时消耗70%
    充电速率 0.069/秒 每10秒增加一次，约2小时充满100%

    5.2 充电触发条件

    agv.IsFree() && agv.IsEmpty() && agv.IsCanUse()
 && agv.Battery < 40
 && !IsCharging(agv)
 && agv.GetValue<string>("状态") == ""

    5.3 充电站选址策略

    1. 优先选择 同楼层空闲 充电站
    2. 同层无空闲 → 跨层（需升降梯有余量）
    3. 使用 API.GetShortest 计算最短路径
    4. 到达后在回调中标记 "正在充电"

    5.4 充电状态与任务抢夺

    电量范围 行为
    < 30% 不可接任务，继续充电
    30~59% 继续充电，等待达到60%
    60~99% 可中断充电接任务（IsWorkingByCharged 返回 true）
    100% 停止充电，车体状况→"停止充电"

    5.5 充电站布局

    8 个充电站分散在不同楼层，确保各楼层均有充电能力：

    充电站Mark 说明
    7229, 7230 充电站组1
    5244, 5245 充电站组2
    8344, 8345 充电站组3
    9967, 9968 充电站组4

    六、货物仿真系统需求

    6.1 初始货物分布

    • 所有"自动生成"货区的站点参与
    • 排除生产口和出库口站点
    • 按 50%比例 随机填充托盘+货物
    • 货物类型：3 种随机货物信息 + 1 种托盘

    6.2 生产口货物生成

    • 周期：310 秒/个（可配置）
    • 分组阶梯延迟：4组入库口，组间偏移12秒，层间偏移6秒
    • 条件：站台无AGV + 站台为空
    • 结果：生成 "托盘_0" + "货物_0"

    6.3 出库口货物消耗

    • 周期：18 秒/个（可配置）
    • 条件：站台有货物 + 无AGV
    • 结果：清除货物

    八、统计与监控需求

    8.1 统计指标

    指标 计算方式 输出频率
    入库完成总数 累计计数 每10秒
    出库完成总数 累计计数 每10秒
    入库平均耗时 总耗时 / 完成数 每10秒
    出库平均耗时 总耗时 / 完成数 每10秒
    入库节拍 累计计时 / 完成数 每10秒
    出库节拍 累计计时 / 完成数 每10秒
    入库效率 完成数 / 计时 × 60 (次/分钟) 每10秒
    出库效率 完成数 / 计时 × 60 (次/分钟) 每10秒
    充电次数 累计计数 每10秒

    8.2 日志输出

    • 每 10 秒输出一次统计摘要
    • 任务创建/完成的追踪日志
    • 异常堆栈追踪输出

    九、并发安全需求

    9.1 多线程同步

    场景 机制 说明
    AGV→站台映射 Hashtable + lock 防重复派车到同一站台
    任务创建 去重检查 同一站点不能有多个未完成任务
    跨层调度 HashSet<string> 防止同一楼层重复派车
    状态机 顺序遍历 定时器中每次遍历不可变快照

    9.2 加锁方法

    方法 功能
    AddHash(agvName, staMark) 添加AGV→站台映射，已存在返回false
    RemoveHash(agvName) 移除映射
    UpdateTargetSta(agvName, staMark) 更新目标站台

    十、异常处理需求

    10.1 异常场景与恢复

    场景 处理方式
    AGV 位置异常（不在取货点/送货点） 状态回退到导航状态，重新 GoTo
    任务创建异常 try-catch 捕获，打印堆栈
    调度主循环异常 try-catch 捕获，不中断循环
    工程未加载 阻塞等待，Thread.Sleep(100) 轮询

    10.2 Kill() 清理流程

    停止脚本时执行： 1. 清空所有 AGV 任务（TaskKillAll） 2. 清空所有 AGV 货物（TakeAll） 3. 重置 AGV 状态标记（状态、类型、车体状况） 4. 清空所有站台货物

    11.1 各文件职责分配

    文件 需包含的功能

    十二、实现路线图

    阶段一：基础框架

    1. 创建项目文件与全局引用
    2. 实现 Main() 入口 — 等待加载、初始化站点列表
    3. 注册生产口 + 出库口站点
    4. 实现 Kill() 清理

    阶段二：AGV 管理

    1. 上线车辆数() — AGV 上线/下线控制
    2. InitAgvBattery() — 电量初始化
    3. AGV/站台自定义属性注册

    阶段三：货物仿真

    1. RandomGenerateCargo() — 随机填充 + 定时生成/消耗
    2. 生产口倒计时分组阶梯逻辑

    阶段四：任务系统

    1. TaskCreat() — 入库/出库任务创建
    2. 防死锁 + 去重检查

    阶段五：调度执行

    1. 任务状态机（入库 + 出库）
    2. AGV 选择策略（同层优先 → 跨层调度）
    3. 防推挤配置

    阶段六：电量管理

    1. SimulateCharge() — 电量消耗与充电
    2. AgvToChargeStation() — 自动充电导航
    3. IsCharging() / IsWorkingByCharged() — 充电状态判断

    阶段七：完善与优化

    1. 统计系统（PrintStats()）
    2. 并发安全（Hashtable + lock）
    3. 异常处理完善
    4. 跨层调度防重复
